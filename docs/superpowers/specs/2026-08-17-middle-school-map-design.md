# 初中地下实验室地图设计

日期：2026-08-17

## 目标

在树人关卡胜利后提供第二阶段“初中地下实验室”地图。地图使用用户提供的 `1872 x 560` 背景图，保留 PC 端宽屏比例，并提供与小学地图一致的可聚焦热点体验：鼠标悬停或键盘聚焦时，区域放大、边缘发光并显示折叠文字；点击或按 Enter/Space 锁定热点。

## 范围

- 新增独立路由 `/middle-map`，不改变现有小学 `/map` 的坐标和行为。
- 将 `初中背景.jpg` 复制为网页本地资源；不依赖扁平化 SVG 读取路径。
- 新建独立 `middle-region-layout.json`，保存五个热点的坐标、路径、中心点和展示文案。
- 五个首版热点：任务总览、知识资料室、人工智能基础、引导实验、模型训练。
- 复现 ReactBits FoldText 的核心视觉：按字符从顶部折页展开、透视和折痕阴影；使用原生 CSS 动画，不新增 GSAP 依赖。
- 树人战斗胜利结算提供“进入初中实验室”按钮，导航到 `/middle-map`；其他模块继续保持“再来一次”。
- 地图提供返回小学地图按钮，沿用全局云转场 Provider 的返回首页契约不变。

## 交互设计

1. 初次进入显示完整背景，不显示热点文字，背景图加载完成后才通知页面就绪。
2. `pointerenter`、`focus` 或触摸等价事件激活一个热点；其他热点保持未激活。
3. 激活状态对同一热点的背景区域做轻微放大（约 1.025 倍），叠加裁剪后的背景图副本，避免只放大描边而内容不动。
4. 激活状态叠加青绿色边缘光线和柔和外发光；不使用大面积遮罩或渐变球体。
5. 标签使用无障碍的真实文本，同时用分字符 `rotateX` 折页动画显示视觉文本。动画在每次新热点激活时重新播放；`prefers-reduced-motion` 下直接显示。
6. 点击/Enter/Space 锁定当前热点，再次点击背景或按 Escape 解除锁定。锁定仅改变展示状态，课程详情入口留给后续内容阶段。

## 实现结构

- `apps/web/src/app/middle-map/page.tsx`：客户端地图页面、状态和 SVG 图层。
- `apps/web/src/app/middle-map/page.module.css`：宽屏画布、热点发光、放大和 FoldText 动画。
- `apps/web/src/app/middle-map/middle-region-layout.json`：五个手工路径及展示元数据。
- `apps/web/public/assets/learning-map/middle-school-lab.jpg`：本地背景资源。
- `apps/web/src/features/ai-battle/ai-battle-game.tsx`：仅为 `tree-sanctuary` 胜利结算增加下一阶段导航动作。

地图坐标统一使用 `viewBox="0 0 1872 560"`。每个热点使用同一份路径作为透明命中区域、发光描边和裁剪放大区域，避免三层几何不一致。

## 方案取舍

- 采用独立 `/middle-map` 而不是给 `/map` 增加查询分支，降低小学地图回归风险。
- 采用独立 JSON 手工路径而不是继续尝试从当前扁平化 SVG 提取，保证坐标可审查、可测试。
- 采用 CSS/原生动画而不是引入 GSAP，保持当前依赖边界并支持降级。

## 验收标准

- `/middle-map` 在 PC 桌面视口显示完整地下实验室背景，无拉伸、裁切错误或水平滚动。
- 五个热点均可鼠标悬停、键盘聚焦和点击；只有当前热点出现放大、发光和标签。
- 标签包含可读的 DOM 文本；折页动画重播稳定，减少动画设置下不发生遮挡或闪烁。
- 树人胜利结算显示“进入初中实验室”，点击后到达 `/middle-map`；其他战斗结算不改变。
- 新增页面测试覆盖路径数量、坐标系、激活状态、标签文本、返回按钮和树人导航；类型检查、目标测试、生产构建及 `git diff --check` 通过。
